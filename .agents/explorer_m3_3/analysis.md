Milestone 3 establishes the interactive visual interface for sentence-level vocabulary learning and speech evaluation in the Oxford 3000™ CEFR Lexicon Application. 

This technical design document specifies:
1. **Interactive Word Tokens (`SentenceTokens.jsx` & `WordToken.jsx`)**: Tokenizes English sentences into clickable, interactive word tokens while preserving punctuation and enforcing strict LTR layout protection (`direction: ltr; unicode-bidi: isolate`) to prevent UI corruption in RTL/mixed language contexts.

## 2. Interactive Word Tokens Component (`SentenceTokens.jsx` & `WordToken.jsx`)

### 2.1 Sentence Tokenization Logic

Tokenizing sentences for interactive rendering requires separating clickable word text from surrounding punctuation without breaking visual sentence structure or corrupting word audio lookups.

#### Token Object Interface
Each token generated by the tokenizer follows this structure:
```typescript
interface TokenItem {
  id: string;                    // Unique token identifier (e.g. "token-0-hello")
  rawToken: string;              // Original token string as split from sentence (e.g. '"Hello,')
  cleanWord: string;             // Lowercased, punctuation-stripped word for TTS & evaluation (e.g. "hello")
  displayWord: string;           // Cased word for UI display (e.g. "Hello")
  leadingPunctuation: string;    // Punctuation attached before the word (e.g. '"', '(')
  trailingPunctuation: string;   // Punctuation attached after the word (e.g. ',', '.', '!"')
  index: number;                 // 0-indexed position within the sentence tokens array
  isWord: boolean;               // True if token contains alphabetic characters
}
```

#### Tokenization Algorithm (`tokenizeSentence`)
```javascript
/**
 * Splits a sentence string into structured word and punctuation tokens.
 * Handles contractions (don't, it's), hyphens (well-known), quotes, and punctuation.
 *
 * @param {string} sentence - Target sentence string
 * @returns {TokenItem[]} Array of structured token objects
 */
export const tokenizeSentence = (sentence = '') => {
  if (!sentence || typeof sentence !== 'string') return [];

  // Split on whitespace while preserving words and punctuation
  const rawTokens = sentence.trim().split(/\s+/);

  return rawTokens.map((rawToken, index) => {
    // Regex matches leading non-word chars, main word (including internal apostrophes/hyphens), and trailing non-word chars
    const match = rawToken.match(/^([^\w\s]*)([\w'-]+)?([^\w\s]*)$/);

    if (!match) {
      return {
        id: `token-${index}-${rawToken}`,
        rawToken,
        cleanWord: rawToken.toLowerCase().replace(/[^\w']/g, ''),
        displayWord: rawToken,
        leadingPunctuation: '',
        trailingPunctuation: '',
        index,
        isWord: true,
      };
    }

    const leadingPunctuation = match[1] || '';
    const wordPart = match[2] || '';
    const trailingPunctuation = match[3] || '';

    const cleanWord = wordPart.toLowerCase().replace(/[^\w']/g, '');
    const isWord = cleanWord.length > 0;

    return {
      id: `token-${index}-${cleanWord || 'punct'}`,
      rawToken,
      cleanWord,
      displayWord: wordPart || rawToken,
      leadingPunctuation,
      trailingPunctuation,
      index,
      isWord,
    };
  });
};
```

### 2.2 Strict LTR Layout Protection Styling

When rendering English sentences in a application that includes Arabic translation strings (`dir="rtl"`), browser engines can scramble word order, punctuation placement, and line wraps if bidirectional text boundaries are not strictly isolated.

#### CSS Protection Specification (`src/index.css`)
```css
/* Strict LTR Layout Isolation Utility */
.ltr-isolate,
[dir="ltr"] {
  direction: ltr !important;
  unicode-bidi: isolate !important;
  text-align: left;
}
```

#### Inline Style Defensive Fallback
To ensure layout stability across all browsers and shadow containers, components explicitly apply both inline styles and Tailwind isolation utilities:
```jsx
style={{ direction: 'ltr', unicodeBidi: 'isolate' }}
```

### 2.3 `WordToken.jsx` Component Specification

`WordToken.jsx` renders a single interactive word token within a sentence.

#### Features:
- **Click Actions**: Trigger single-word audio TTS playback or select word for target practice.
- **Target Word Highlight**: Highlights target vocabulary (e.g. Oxford 3000 entry word) with a distinct cyan outline/glow.
- **Evaluation Status Highlight**: Renders green background tag if matched (`match: true`) or red background tag if mismatched (`match: false`).
- **Active Playing Pulse**: Animates when the word is currently being spoken by audio TTS.

#### Complete React Implementation (`src/components/WordToken.jsx`)
```jsx
import React from 'react';

/**
 * WordToken — Renders an individual clickable word token with punctuation isolation and status badges.
 */
export const WordToken = React.memo(({
  token,
  isTarget = false,
  evaluationMatch = null, // true = matched (green), false = mismatched (red), null = un-evaluated
  isPlaying = false,
  onWordClick,
  onWordPractice,
  disabled = false
}) => {
  const { displayWord, cleanWord, leadingPunctuation, trailingPunctuation, isWord, index } = token;

  if (!isWord) {
    return <span className="text-slate-400 font-normal">{token.rawToken} </span>;
  }

  const handleClick = (e) => {
    e.stopPropagation();
    if (disabled) return;
    if (onWordClick) {
      onWordClick(token);
    }
  };

  const handleContextMenu = (e) => {
    e.preventDefault();
    e.stopPropagation();
    if (disabled) return;
    if (onWordPractice) {
      onWordPractice(token);
    }
  };

  // Determine styling based on evaluation, target, and playing states
  let badgeStyle = 'hover:bg-cyan-500/20 hover:text-cyan-200 text-slate-200 border-transparent';

  if (isPlaying) {
    badgeStyle = 'bg-cyan-500 text-slate-950 font-bold border-cyan-400 animate-pulse shadow-[0_0_12px_rgba(6,182,212,0.6)]';
  } else if (evaluationMatch === true) {
    badgeStyle = 'bg-emerald-500/25 text-emerald-300 border-emerald-500/50 shadow-[0_0_8px_rgba(16,185,129,0.2)]';
  } else if (evaluationMatch === false) {
    badgeStyle = 'bg-rose-500/25 text-rose-300 border-rose-500/50 shadow-[0_0_8px_rgba(244,63,94,0.2)]';
  } else if (isTarget) {
    badgeStyle = 'bg-cyan-950/80 text-cyan-300 border-cyan-500/60 font-semibold ring-1 ring-cyan-400/40';
  }

  return (
    <span
      dir="ltr"
      className="inline-flex items-center ltr-isolate whitespace-nowrap"
      style={{ direction: 'ltr', unicodeBidi: 'isolate' }}
    >
      {/* Leading Punctuation */}
      {leadingPunctuation && (
        <span className="text-slate-400 select-none mr-[1px]">{leadingPunctuation}</span>
      )}

      {/* Interactive Word Pill */}
      <button
        type="button"
        onClick={handleClick}
        onContextMenu={handleContextMenu}
        disabled={disabled}
        title={`Click to listen ("${cleanWord}") | Right-click to practice`}
        aria-label={`Word ${displayWord}. Click to listen.`}
        className={`px-1.5 py-0.5 my-0.5 rounded-md text-sm sm:text-base transition-all duration-200 border cursor-pointer select-none focus:outline-none focus:ring-2 focus:ring-cyan-400 ${badgeStyle}`}
      >
        {displayWord}
      </button>

      {/* Trailing Punctuation & Inter-word Space */}
      {trailingPunctuation && (
        <span className="text-slate-400 select-none ml-[1px]">{trailingPunctuation}</span>
      )}
      <span className="select-none">&nbsp;</span>
    </span>
  );
});

export default WordToken;
```

### 2.4 `SentenceTokens.jsx` Component Specification

`SentenceTokens.jsx` tokenizes a full sentence and maps each token through `WordToken.jsx`.

#### Props Contract (`SentenceTokens.jsx`)
| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `sentence` | `string` | `''` | Target English sentence string |
| `targetWords` | `string[] \| object[]` | `[]` | Words to highlight as target vocabulary |
| `evaluationResult` | `object \| null` | `null` | `{ score, wordBreakdown: [{ word, match }] }` result object |
| `activeWordIndex` | `number \| null` | `null` | Currently playing token index |
| `onWordClick` | `function(token)` | `null` | Callback when a word token is clicked |
| `onWordPractice` | `function(token)` | `null` | Callback when a word token is right-clicked / selected for practice |
| `className` | `string` | `''` | Additional styling container classes |

#### Complete React Implementation (`src/components/SentenceTokens.jsx`)
```jsx
import React, { useMemo } from 'react';
import { tokenizeSentence } from '../utils/tokenUtils'; // or embedded helper
import WordToken from './WordToken';

export const SentenceTokens = React.memo(({
  sentence = '',
  targetWords = [],
  evaluationResult = null,
  activeWordIndex = null,
  onWordClick,
  onWordPractice,
  className = ''
}) => {
  // Tokenize sentence into structured items
  const tokens = useMemo(() => tokenizeSentence(sentence), [sentence]);

  // Normalize target words array into lowercased Set for quick lookup
  const targetSet = useMemo(() => {
    const set = new Set();
    if (Array.isArray(targetWords)) {
      targetWords.forEach((item) => {
        if (typeof item === 'string') set.add(item.toLowerCase());
        else if (item && item.word) set.add(item.word.toLowerCase());
      });
    }
    return set;
  }, [targetWords]);

  // Create evaluation map: cleanWord -> match boolean
  const evaluationMap = useMemo(() => {
    if (!evaluationResult || !Array.isArray(evaluationResult.wordBreakdown)) {
      return null;
    }
    const map = new Map();
    evaluationResult.wordBreakdown.forEach((item) => {
      map.set(item.word.toLowerCase(), item.match);
    });
    return map;
  }, [evaluationResult]);

  if (!sentence) return null;

  return (
    <div
      dir="ltr"
      className={`ltr-isolate flex flex-wrap items-center leading-relaxed text-slate-100 ${className}`}
      style={{ direction: 'ltr', unicodeBidi: 'isolate' }}
    >
      {tokens.map((token) => {
        const isTarget = targetSet.has(token.cleanWord);
        const evalMatch = evaluationMap ? evaluationMap.get(token.cleanWord) : null;
        const isPlaying = activeWordIndex === token.index;

        return (
          <WordToken
            key={token.id}
            token={token}
            isTarget={isTarget}
            evaluationMatch={evalMatch !== undefined ? evalMatch : null}
            isPlaying={isPlaying}
            onWordClick={onWordClick}
            onWordPractice={onWordPractice}
          />
        );
      })}
    </div>
  );
});

export default SentenceTokens;
```

## 3. Score Visualizer Component (`SpeechScoreVisualizer.jsx` & `ScoreBadge.jsx`)

### 3.1 `ScoreBadge.jsx` Component Specification

`ScoreBadge.jsx` renders individual word evaluation pills with explicit Green `✓` badges for matches and Red `✗` badges for mismatches.

#### Complete React Implementation (`src/components/ScoreBadge.jsx`)
```jsx
import React from 'react';

/**
 * ScoreBadge — Visual status pill for individual word speech evaluation.
 */
export const ScoreBadge = React.memo(({
  word,
  match = false,
  ipa = '',
  onPractice
}) => {
  const handleClick = () => {
    if (onPractice && typeof onPractice === 'function') {
      onPractice(word);
    }
  };

  return (
    <span
      dir="ltr"
      className={`inline-flex items-center gap-1.5 px-3 py-1 rounded-xl border text-xs sm:text-sm font-medium transition-all ${
        match
          ? 'bg-emerald-500/15 text-emerald-300 border-emerald-500/40 shadow-[0_0_10px_rgba(16,185,129,0.15)]'
          : 'bg-rose-500/15 text-rose-300 border-rose-500/40 shadow-[0_0_10px_rgba(244,63,94,0.15)]'
      }`}
      style={{ direction: 'ltr', unicodeBidi: 'isolate' }}
    >
      {/* Icon Badge */}
      <span
        aria-hidden="true"
        className={`w-4 h-4 rounded-full flex items-center justify-center text-[10px] font-bold ${
          match ? 'bg-emerald-500/30 text-emerald-300' : 'bg-rose-500/30 text-rose-300'
        }`}
      >
        {match ? '✓' : '✗'}
      </span>

      {/* Word String */}
      <span className="font-semibold tracking-wide">{word}</span>

      {/* IPA Phonetic Tag if provided */}
      {ipa && !match && (
        <span className="font-mono text-[11px] opacity-80 text-rose-200 font-normal">
          [{ipa}]
        </span>
      )}

      {/* Screen Reader Text */}
      <span className="sr-only">{match ? 'Correct' : 'Mismatched'}</span>

      {/* Audio Practice Button for missed words */}
      {!match && onPractice && (
        <button
          type="button"
          onClick={handleClick}
          className="ml-1 p-0.5 hover:text-white text-rose-300 transition-colors"
          title={`Practice pronunciation for "${word}"`}
          aria-label={`Listen to correct pronunciation for ${word}`}
        >
          <svg className="w-3.5 h-3.5" fill="none" stroke="currentColor" viewBox="0 0 24 24">
            <path strokeLinecap="round" strokeLinejoin="round" strokeWidth="2" d="M15.536 8.464a5 5 0 010 7.072M5.586 15H4a1 1 0 01-1-1v-4a1 1 0 011-1h1.586l4.707-4.707C10.923 3.663 12 4.109 12 5v14c0 .891-1.077 1.337-1.707.707L5.586 15z" />
          </svg>
        </button>
      )}
    </span>
  );
});

export default ScoreBadge;
```

### 3.2 `SpeechScoreVisualizer.jsx` Component Specification

`SpeechScoreVisualizer.jsx` provides a visual breakdown panel for speech evaluation results.

#### Visual Architecture:
1. **Overall Score Meter & Status Banner**:
   - Score $\ge 90\%$: Green (`Emerald`) — "Excellent Pronunciation!"
   - Score $70\% - 89\%$: Teal/Cyan — "Good Effort! Keep practicing."
   - Score $< 70\%$: Amber/Rose — "Needs Practice. Try again!"
2. **Word Breakdown Grid**: Renders `ScoreBadge` pills for every token in the sentence.
3. **Phonetic & Mispronunciation Detail Box**: Displays targeted IPA phonetics and retry triggers for words marked `match: false`.

#### Complete React Implementation (`src/components/SpeechScoreVisualizer.jsx`)
```jsx
import React from 'react';
import ScoreBadge from './ScoreBadge';
import { playAudio } from '../services/audioService';

export const SpeechScoreVisualizer = React.memo(({
  evaluationResult,
  spokenText = '',
  onRetry,
  onPracticeWord,
  showPhonetics = true,
  className = ''
}) => {
  if (!evaluationResult) return null;

  const { score = 0, wordBreakdown = [] } = evaluationResult;

  // Determine score status theme
  let statusTheme = {
    bg: 'bg-emerald-950/40 border-emerald-500/40 text-emerald-300',
    gaugeColor: '#10b981',
    label: 'Excellent Pronunciation! 🎉',
  };

  if (score < 70) {
    statusTheme = {
      bg: 'bg-rose-950/40 border-rose-500/40 text-rose-300',
      gaugeColor: '#f43f5e',
      label: 'Needs Practice. Try Again! 💪',
    };
  } else if (score < 90) {
    statusTheme = {
      bg: 'bg-teal-950/40 border-teal-500/40 text-teal-300',
      gaugeColor: '#14b8a6',
      label: 'Good Effort! Almost Perfect! 👍',
    };
  }

  const missedWords = wordBreakdown.filter((item) => !item.match);

  const handlePracticeWord = (word) => {
    playAudio(word, 'en-US', 0.85);
    if (onPracticeWord) onPracticeWord(word);
  };

  return (
    <div
      dir="ltr"
      className={`glass-panel p-5 rounded-2xl border ${statusTheme.bg} space-y-4 ltr-isolate ${className}`}
      style={{ direction: 'ltr', unicodeBidi: 'isolate' }}
    >
      {/* Top Header Row: Score Circular Meter + Status Badge + Retry Button */}
      <div className="flex items-center justify-between gap-4 flex-wrap">
        <div className="flex items-center gap-3">
          {/* Circular Score Percentage Badge */}
          <div className="relative w-14 h-14 flex items-center justify-center rounded-full bg-slate-900/80 border border-slate-700/60 shadow-inner">
            <span className="text-lg font-extrabold text-white tracking-tight">
              {score}%
            </span>
          </div>

          <div>
            <h4 className="text-base font-bold text-white tracking-wide">Speech Evaluation</h4>
            <p className="text-xs font-semibold mt-0.5">{statusTheme.label}</p>
          </div>
        </div>

        {/* Retry Button */}
        {onRetry && (
          <button
            type="button"
            onClick={onRetry}
            className="flex items-center gap-1.5 px-3 py-1.5 rounded-xl bg-slate-800/80 hover:bg-slate-700 text-slate-200 hover:text-white border border-slate-600/60 text-xs font-semibold transition-all shadow-sm"
          >
            <svg className="w-4 h-4" fill="none" stroke="currentColor" viewBox="0 0 24 24">
              <path strokeLinecap="round" strokeLinejoin="round" strokeWidth="2" d="M19 11a7 7 0 01-7 7m0 0a7 7 0 01-7-7m7 7v4m0 0H8m4 0h4m-4-8a3 3 0 100-6 3 3 0 000 6z" />
            </svg>
            <span>Try Again</span>
          </button>
        )}
      </div>

      {/* Spoken Transcript Row */}
      {spokenText && (
        <div className="bg-slate-900/60 p-3 rounded-xl border border-slate-800/60 text-xs">
          <span className="text-slate-400 font-medium">Recognized Speech: </span>
          <span className="text-slate-200 italic font-mono">"{spokenText}"</span>
        </div>
      )}

      {/* Word-by-Word Evaluation Breakdown Badges */}
      <div className="space-y-2">
        <h5 className="text-xs font-bold text-slate-300 uppercase tracking-wider">Word Breakdown</h5>
        <div className="flex flex-wrap items-center gap-2">
          {wordBreakdown.map((item, idx) => (
            <ScoreBadge
              key={`score-badge-${idx}-${item.word}`}
              word={item.word}
              match={item.match}
              onPractice={handlePracticeWord}
            />
          ))}
        </div>
      </div>

      {/* Mispronounced Words Action Panel */}
      {showPhonetics && missedWords.length > 0 && (
        <div className="bg-rose-950/20 border border-rose-900/40 p-3.5 rounded-xl text-xs space-y-2">
          <span className="font-bold text-rose-300 flex items-center gap-1.5">

            Words to Practice ({missedWords.length}):

          <div className="flex flex-wrap gap-2 pt-1">
            {missedWords.map((item, i) => (

                type="button"
                onClick={() => handlePracticeWord(item.word)}
                className="flex items-center gap-1.5 px-2.5 py-1 rounded-lg bg-rose-900/40 hover:bg-rose-900/70 border border-rose-700/50 text-rose-200 transition-all"

                <span className="font-semibold">{item.word}</span>

        </div>
      )}
    </div>
  );
```

### 4.2 Integration Pattern 2: `Storyteller.jsx`

`Storyteller.jsx` generates contextual stories using Gemini AI. Each story line is an interactive sentence that users can listen to and practice pronouncing.

#### Integration Blueprint & Component Architecture:
```jsx
import React, { useState } from 'react';
import SentenceTokens from './SentenceTokens';
import SpeechScoreVisualizer from './SpeechScoreVisualizer';
import { playAudio } from '../services/audioService';
import speechEvaluation from '../services/speechEvaluation';

export const Storyteller = () => {
  const [activeLineIndex, setActiveLineIndex] = useState(null);
  const [isRecording, setIsRecording] = useState(false);
  const [spokenTranscript, setSpokenTranscript] = useState('');
  const [lineEvaluations, setLineEvaluations] = useState({}); // { [lineIndex]: result }

  const handlePracticeLine = (lineText, index) => {
    setActiveLineIndex(index);
    setIsRecording(true);

    speechEvaluation.startListening(
      (transcript) => {
        setIsRecording(false);
        setSpokenTranscript(transcript);
        const result = speechEvaluation.evaluateSpeech(lineText, transcript);
        setLineEvaluations((prev) => ({ ...prev, [index]: result }));
      },
      (error) => {
        setIsRecording(false);
        console.error('Speech error:', error);
      }
    );
  };

  return (
    <div className="space-y-6">
      {/* Story Line Container */}
      {storyLines.map((line, idx) => (
        <div key={`story-line-${idx}`} className="glass-panel p-5 rounded-2xl space-y-3">
          <div className="flex items-start justify-between gap-3">
            {/* Interactive Sentence Tokens */}
            <SentenceTokens
              sentence={line.text}
              targetWords={line.targetWords}
              evaluationResult={lineEvaluations[idx]}
              onWordClick={(token) => playAudio(token.cleanWord, 'en-US', 0.9)}
            />

            {/* Mic Practice Button */}
            <button
              onClick={() => handlePracticeLine(line.text, idx)}
              className={`p-2.5 rounded-xl border transition-all ${
                isRecording && activeLineIndex === idx
                  ? 'bg-rose-500 text-white animate-pulse'
                  : 'bg-slate-900 text-cyan-400 border-cyan-800/40 hover:bg-cyan-500/20'
              }`}
              title="Practice speaking this sentence"
            >
              🎤
            </button>
          </div>

          {/* Render Speech Score Visualizer if line was evaluated */}
          {lineEvaluations[idx] && (
            <SpeechScoreVisualizer
              evaluationResult={lineEvaluations[idx]}
              spokenText={spokenTranscript}
              onRetry={() => handlePracticeLine(line.text, idx)}
            />
          )}
        </div>
      ))}
    </div>
  );
};
```
